# Tetris Lite

Gioco Tetris Android leggero con controlli touch.

## Funzioni
- 7 tetramini classici
- Griglia 10×20
- Comandi touch e pulsanti a schermo
- Punteggio, linee e livelli
- Velocità crescente con il livello
- Pezzo speciale **PERFORATORE** 1×1 con comparsa casuale al 9%: attraversa e cancella i blocchi della colonna fino in fondo
- Nessuna connessione Internet richiesta

## Comandi
- **← / →**: sposta il pezzo
- **↻**: ruota
- **DROP**: caduta immediata
- Swipe orizzontale: sposta
- Swipe verso il basso: caduta immediata
- Tap / swipe verso l’alto: ruota

## APK
Ogni push su `main` avvia la GitHub Action **Build APK**. Al termine, l'APK debug è disponibile negli artifact della run con il nome `TetrisLite-debug-apk`.
